# Switcher
Este videojuego se diseñó a partir del género de puzzles cooperativos, con tintes de aventura y horror. Ambientado en los pasillos de una nave espacial accidentada, invita a dos jugadores a trabajar juntos, comunicarse y sortear obstáculos de diversos tipos. El objetivo es que ambos usuarios logren llevar a sus personajes hasta el final de cada escenario, ya sea resolviendo rompecabezas o evitando amenazas, hasta lograr escapar. 

Características principales

Jugabilidad Cooperativa
Estética PixelArt en Blanco y Negro
Resolución de Puzzles
Tintes de Horror y Suspenso

Proyecto realizado para la materia “Introducción a los Videojuegos” en [https://unahur.edu.ar](UNAHUR).
